Blue & Pink Expense Tracker — separated files

Files:
- login.html: login page
- register.html: new account registration page
- main.html: expense tracker main page
- style.css: all shared styling
- app.js: login, registration, transaction, profile and navigation logic

Run:
1. Keep all five files in the same folder.
2. Open login.html in a browser, or use VS Code Live Server.
3. Create an account, then add income and expenses.

Important:
This is a front-end demo. User accounts and transaction data are stored in browser localStorage.
Passwords are stored as plain text, so this is NOT secure for real users or deployment.
For a real Django application, authentication and transactions should be handled server-side.
